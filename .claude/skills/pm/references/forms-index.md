# Form index

Every form in *A Project Manager's Book of Forms*, 3rd edition (Cynthia Snyder
Dionisio, Wiley 2017), the companion to the PMBOK Guide 6th edition.

Page numbers are **PDF pages**, which is what `pdftotext` and the Read tool take.
PDF page = printed book page + 11.

- **Prose pages** hold the form's purpose, Tailoring Tips, Alignment, and the
  Document Element / Description table.
- **Blank pages** hold the printed form itself. These are the authority on field
  names and field order.
- **Kind** decides how the form becomes Markdown. See `rendering.md`.

## Kinds

| Kind | Shape on the page | Count |
| --- | --- | --- |
| `fields` | Labelled boxes to write prose into | 32 |
| `log` | A register: one row per record, fixed columns | 22 |
| `matrix` | A grid crossing two dimensions | 4 |
| `chart` | A timeline, Gantt, S-curve or swim lane | 4 |
| `diagram` | A node-and-arrow network | 1 |
| `outline` | A numbered decomposition hierarchy | 2 |
| `narrative` | A fill-in-the-blank sentence template | 1 |

## Notes on particular forms

- **1.1 Project Charter** is four pages and is already reproduced in
  `docs/charter-package.en.md` Part 2B. Match that rendering.
- **2.7** has two grids: the traceability matrix and the inter-requirements
  traceability matrix on the second page.
- **2.34 Probability and Impact Assessment** prints as PROBABILITY AND IMPACT
  RISK RATING; **4.8** prints as CONTRACT CLOSEOUT; **4.9** prints as FORMAL
  ACCEPTANCE FORM. The extractor reports both names.
- **6.3 Release Plan** is the one form with no `Page N of M` footer.
